Snowflake interview practice

Six free questions with answers from the course.

No invented scale numbers.

Edition and region still change what you are allowed to claim in a design interview.

1. Why is a virtual warehouse not the same thing as storage?

Tables live in the storage layer.

A warehouse is a compute cluster that queries that storage.

Two warehouses can read the same tables.

Suspending a warehouse stops its compute credits and leaves the data in place.

2. What is the Standard Edition limit for Time Travel, and what is Fail-safe?

Standard Time Travel is up to one day.

Enterprise and above can extend it to 90 days.

Fail-safe is a further 7 days of recovery that only Snowflake can attempt.

You cannot query Fail-safe.

3. When would you add a cluster instead of resizing a warehouse?

Resize when one query needs more CPU or memory.

Add a cluster, on Enterprise multi-cluster warehouses, when many queries need to run at the same time.

Clusters do not duplicate storage.

4. What does a stream consume, and what does a dynamic table declare?

A stream is a bookmark of changes and advances when DML commits against it.

A dynamic table declares a SELECT and a freshness target.

The minimum target lag is one minute.

Procedures and MERGE stay on tasks.

5. How do you keep a dbt pull request off the production database?

Clone the production database, point a dbt target at the clone, run dbt build, and drop the clone.

The clone shares micro-partitions until the run writes.

Give that run its own warehouse with auto-suspend.

6. What should you verify before calling a Cortex function in production?

That the function is available in your region, that it is not still marked Preview, that the role has the AI function privileges, and that AI Credits are an acceptable separate charge.

Cortex Agents have been generally available since 4 November 2025.

Analytical search is a separate switch.

What not to claim in the room

Do not quote a credit price, a trial dollar balance, or a query speed.

Those depend on the contract, the region, and the data.

Do not say every Cortex function is generally available.

Read the function's own status and the account's region.

Do not say a primary key rejects duplicates.

Snowflake stores the constraint and does not enforce it.

Do not say Fail-safe is something you can query.

It is a 7-day recovery window for Snowflake, after Time Travel ends.

Do not say 5X-Large and 6X-Large exist in every region.

The size page marks them generally available on AWS and Azure, and in preview in US Government regions.

Password login for the dbt Snowflake adapter is the wrong default after 31 August 2026.

Talk about key-pair or SSO, and mention the documented LEGACY_SERVICE exception if the interviewer asks about old service users.

A 60-second structure

Name the layer first: storage, warehouse, or cloud services.

Name the edition gate if the feature has one. Multi-cluster, masking, 90-day Time Travel, search optimization, materialized views, and query acceleration start at Enterprise.

Name the cost: warehouse seconds, serverless credits, storage bytes, or AI Credits.

Name the limit you looked up: region, preview label, or the 60-second warehouse minimum.

Stop. A precise limit beats a made-up benchmark.

If you do not remember the edition, say you would check the edition matrix before you promise the feature.

If you do not remember the region, say you would check the feature's region list before you promise the demo.

Say which official page you would open. Naming the page is a stronger answer than a guessed number.

Offer to draw the three layers before you draw a pipeline.

Offer a clone for the pull request before you offer a full copy of the data.

Mention auto-suspend in seconds, and the 60-second minimum when a warehouse resumes.

Mention that search optimization and materialized views are different tools.

Search optimization is for a selective point lookup. A materialized view is a stored query on one table.

Both of those start at Enterprise Edition. Say that before you recommend them.
