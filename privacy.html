Privacy

Data For Dummies stores only what the site needs to teach, sign you in, and take a Pro payment. This page says what that is. It is not a promise that a third-party tool has been audited.

Account

If you create an account, the Cloudflare database stores your email, a password hash (not the password), your name and phone if you typed them, and whether the email code was confirmed. Session tokens are stored as hashes.

Learning

When you are signed in and save a lesson, the database stores the course, the lesson id, and the time that save happened. A completion request stores that same list. The site does not invent a finished course or a certificate.

Visits

Pages send a random visitor id from this browser, the page path, a coarse device and browser name, and the country Cloudflare already sees on the request. The funnel counts course views, signups, a first saved lesson, the Pro page, checkout, and an active subscription. It does not put your email in those events.

Payments

Pro is billed by Razorpay for FKTech. Razorpay handles the card or UPI screen. The site stores the subscription id, plan, status, and captured payment ids so access and the admin revenue total can be checked. Card numbers are not stored here.

Email

Confirmation and password-reset codes are sent with Resend from no-reply@datafordummies.in. The code expires after 15 minutes.

What this site does not do

There is no private forum. The public contacts are the YouTube channel, the GitHub repository, and email. The site does not sell learner lists. Old Firebase analytics in the browser were removed. Accounts are not stored in Supabase.
