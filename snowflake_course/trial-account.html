Trial account and Snowsight

A trial is a real Snowflake account with a free usage balance, a cloud, a region, and an edition.

Sign in to save your place.

Picture it this way

Signing up is like getting a temporary library card. You pick the city (the cloud region), the kind of card (the edition), and you receive a prepaid balance. The card works for 30 days or until the balance is gone, whichever happens first. The reading room on the web is called Snowsight.

What the signup actually chooses

Snowflake's trial documentation says you select the cloud platform, the region, and the Snowflake edition when you sign up. Those choices change which features exist and how fast the free balance falls. Enterprise features can consume extra credits.

The trial lasts 30 days from the sign-up date, or until the free usage balance is used up, whichever comes first. You can cancel during the trial or upgrade to a paid account. Upgrading ends the free trial and moves the account to on-demand billing. Remaining trial credits still apply. This course does not state a dollar value for the balance, because the signup page is the place that shows the current offer.

You also choose an account identifier. Prefer the organization name plus the account name. An older account locator still exists, and VPS locators use a different format.

Snowsight is the web app

Snowsight is the web interface for worksheets, dashboards, history, and admin. It is included on every edition in the current edition matrix. Worksheets run SQL. Query History is where you open the query profile after a statement finishes.

The same account can be reached from SnowSQL, the Snowflake CLI, Python connectors, JDBC, and ODBC. The worksheet is the fastest place to learn. A load command such as PUT is a client command. It does not run inside the browser worksheet.

Keep the trial small. Create one X-Small warehouse, turn on auto-suspend, and do not leave a large warehouse running while you read. Storage for loaded files and Time Travel also reduces the free balance.

Region is sticky for this practice

Cortex features, 5X-Large and 6X-Large warehouses, and private networking are not available in every region. Pick the region your company will really use, then check that region's feature list before you build a demo that depends on Cortex or a very large warehouse.

A safe first session

After Snowsight opens, confirm the role, warehouse, database, and schema shown above the worksheet. A query with no warehouse selected cannot run. ACCOUNTADMIN is the role that can create account-level objects such as resource monitors. Use a narrower role for everyday SQL once the account exists.

Find the edition without guessing. If your role can read organization usage, the accounts view has an edition column. Otherwise look at the account details in Snowsight.

Lab: context, edition, and a warehouse that sleeps

Run the context query in a worksheet. Create the warehouse only if you do not already have one. AUTO_SUSPEND is in seconds. 300 is five minutes, which matches Snowflake's advice to keep the idle window short because billing is per second. The 60-second minimum still applies each time the warehouse resumes.

SELECT CURRENT_ROLE() AS role_name,
       CURRENT_WAREHOUSE() AS warehouse_name,
       CURRENT_REGION() AS region_name;

CREATE WAREHOUSE IF NOT EXISTS LEARN_WH
  WAREHOUSE_SIZE = XSMALL
  AUTO_SUSPEND = 300
  AUTO_RESUME = TRUE
  INITIALLY_SUSPENDED = TRUE
  COMMENT = 'Course warehouse. Suspends after 5 idle minutes.';

USE WAREHOUSE LEARN_WH;

Concept summary

  • A trial is 30 days or until the free usage balance is consumed.
  • Cloud, region, and edition are chosen at signup and affect features and credit burn.
  • Snowsight is the web UI. PUT is a client command, not a worksheet command.
  • An X-Small warehouse with a short auto-suspend protects a trial balance.
