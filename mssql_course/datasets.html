Queries to try

After SampleDB loads, these three questions match the columns in the script. Write them yourself before you read them as a hint.

-- Products in Electronics, cheapest first.
SELECT ProductName, UnitPrice
FROM dbo.Products
WHERE Category = 'Electronics'
ORDER BY UnitPrice;

-- How many orders each customer has, including a customer with none
-- if you loaded only the sample customers who did order.
SELECT c.CustomerName, COUNT(o.OrderID) AS orders
FROM dbo.Customers AS c
LEFT JOIN dbo.Orders AS o ON o.CustomerID = c.CustomerID
GROUP BY c.CustomerName;

-- Revenue by category. Quantity times unit price.
SELECT p.Category, SUM(o.Quantity * p.UnitPrice) AS revenue
FROM dbo.Orders AS o
JOIN dbo.Products AS p ON p.ProductID = o.ProductID
GROUP BY p.Category;

The exercise file has seven prompts and no answers. Run SampleDB first, then fill the prompts in that file. A correct answer returns rows. An answer that errors is still progress if you can say which object name was wrong.

Import the CSV

The CSV repeats the customer on each order line. That is a flat extract, not the three tables. Right-click the database, choose Tasks, then Import Data, and land it in a new table such as dbo.OrdersFlat. Compare a count of distinct customer names in the flat table with dbo.Customers. They should agree for this sample. If they do not, the import guessed a type and dropped a row, or you imported the header as data.
