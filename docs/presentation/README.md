# Data For Dummies mobile product presentation

This approval deck tells the Android and iOS product story from the perspective
of a guest explorer, signed-in learner, existing Pro learner and account owner.
It covers the learning journey, feature set, account lifecycle, security
boundaries, architecture, quality evidence and remaining store-owner actions.

## Presentation files

- `generated/data-for-dummies-mobile-product-story.pptx` — presentation copy
- `generated/data-for-dummies-mobile-product-story.pdf` — share/review copy
- `generated/data-for-dummies-contact-sheet.jpg` — whole-deck visual overview
- `generated/slides/` — individual PNG and SVG slides
- `presentation.json` — editable narrative, palette and slide content
- `assets` — verified Android release screenshot used on the cover

## Claim boundary

The deck describes the product that exists in this repository. It does not
claim App Store or Play Store approval, a signed iOS binary, real payment or
email testing, or a guarantee that no future defect can exist. Those remaining
owner-controlled steps are stated directly in the deck.
