# Android app file

The APK is not in this Git repository. `app-debug.apk` and `apk/FK-Learning-Hub.apk` were removed on 13 October 2026 because each was about 55 MB and no live page linked them.

The download used on the site is the public Google Drive folder already in the navigation:

https://drive.google.com/drive/folders/13l354RgeGMsznlmdwU7WSOnOYUP9fhEp?usp=sharing

`apk/index.html` sends that same folder. An old address such as `/apk/FK-Learning-Hub.apk` is no longer a file on GitHub Pages. Use the Drive folder.

Do not commit a new APK here. Put a rebuilt file in that Drive folder, or attach it to a GitHub release and change the navigation link to the release URL you actually published.
