Meet Terraform and OpenTofu

Terraform and OpenTofu both read HCL and both keep a state file. They are not one product with two names.

Sign in to save your place.

Picture it this way

You write a shopping list for servers and databases. The tool goes to the shop and tries to make the shop match the list. Terraform is HashiCorp's list-runner. OpenTofu is a separate list-runner that started from an older public copy of the same idea.

Infrastructure as code

A Terraform configuration describes resources. terraform plan prints what would change. terraform apply asks the providers to make those changes and writes the result into a state file. The state file is how the next plan knows which real object belongs to which block.

The tool does not invent your cloud account. A provider plugin talks to AWS, Azure, Google Cloud, or something else. No provider, no resources.

Two projects after 2023

HashiCorp changed the Terraform license to the Business Source License on 10 August 2023. OpenTofu is a Linux Foundation project under the Mozilla Public License 2.0. It was forked from the Terraform codebase that was still under that public license.

The commands look alike because of that history. terraform plan and tofu plan are not a contract that every later feature exists in both, or that a HashiCorp cloud product will run the OpenTofu binary. The security lesson compares them without calling them equivalent.

Concept summary

  • Plan shows a diff. Apply changes real resources and writes state.
  • OpenTofu and Terraform share ancestry and not a license or a cloud product.
  • HCP Terraform is HashiCorp's hosted product.
