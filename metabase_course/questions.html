Asking questions

The query builder is a notebook: filter rows, summarize them, and draw the result.

Sign in to save your place.

Picture it this way

The query builder is a stack of instructions. First you point at a table. Then you throw away rows you do not want. Then you squash the remaining rows into a number or a group. The chart is only the last instruction, drawn on screen.

Build a question without SQL

Open New, then Question, and pick a table. The notebook editor adds steps. A filter keeps rows. Summarize turns many rows into fewer rows: a count, a sum, an average, or a distinct count. Group by decides the buckets. Sort and row limit decide what the chart is allowed to show.

Save the question into a collection as soon as it answers something a colleague would ask again. An unsaved question disappears with the tab.

Pick a chart that matches the grain

A single number is right when the question is one measure, such as revenue this month. A line is right when the group is time. A bar is right when the group is a category. A table is right when the reader needs the rows, not a picture of them. A map needs a geographic column Metabase recognizes.

If the number looks wrong, check the filter and the grain before you restyle the chart. Summing an amount that is already a monthly total will double-count. Counting orders when the table is order lines will over-count orders.

Name the question as the answer

"Paid revenue by month" is a question a person can find. "Query 3" is a question they will rebuild.
