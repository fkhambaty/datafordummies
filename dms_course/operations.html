Pick compute on purpose. Size it for the log, not for the sales diagram. When a task fails, read the log and the network before you change the mapping.

Picture it this way

A rented truck costs money while it sits in the yard. A yard that hands you trucks still has a minimum and a maximum. Neither truck fixes a locked gate.

Instance or serverless

A replication instance has a class and a disk. It is billed while it exists, including evenings when the task is idle, until you stop or delete it. Storage that fills will stall the task. Multi-AZ keeps a standby and costs more. Read the current DMS pricing page for the class. Do not reuse a price from this course.

A serverless replication config asks for a minimum and maximum capacity in DMS capacity units. AWS has changed how idle capacity is billed. The current serverless pricing and user-guide pages win over any sentence that says it always scales to zero or never does. Schema conversion projects are also called serverless and they are not this capacity range. Do not mix the two bills.

A short troubleshooting order

Test the endpoint again. Read the task log in CloudWatch. Check source log retention and disk. Check target disk and connections. Look at CDC latency and instance free memory or serverless capacity. Only then change table mappings.

Swap files on a replication instance are a sign the class is too small for the LOB or the parallelism you chose. A bigger instance is a test, not a personality.

Security habits

Private subnets, security groups that name the DMS client, secrets instead of pasted passwords, and IAM roles that can read those secrets and write logs. Encryption in transit is the endpoint SSL mode the database requires. Encryption at rest is the storage setting on the databases and on DMS storage, documented per feature. Turn on what those pages describe. Do not assume a new account already did.

Concept summary

  • Instances bill while they exist. Serverless bills by the capacity rules on the current price page.
  • Schema conversion serverless is not replication serverless.
  • Logs, endpoints, and source disk come before a bigger instance.
