Assessments, SCT, and schema conversion

DMS has a premigration assessment on a task, a schema conversion assessment inside DMS Schema Conversion, and the older AWS Schema Conversion Tool. They are three reports. Mixing the names is how a project skips the wrong work.

Picture it this way

One checklist asks whether the moving truck can get out of the driveway. Another checklist asks whether the furniture will fit in the new house. A desktop app can write that second checklist too. They are not the same clipboard.

Premigration assessment

A premigration assessment runs against a replication task. It looks for DMS prerequisites: supplemental logging, primary keys, unsupported data types, LOB settings, and similar task blockers. It does not convert a stored procedure from one database language to another.

Read the assessment before the first full load, and again if you change table mappings. A green assessment is not a green cutover.

AWS SCT is a separate application

The AWS Schema Conversion Tool is a desktop application you install. It assesses and converts schema and database code for heterogeneous moves. It is not a replication task and it is not installed by creating a DMS endpoint.

DMS Schema Conversion is a feature in the DMS console. AWS describes it as built on the SCT conversion engine, and as serverless in the sense that a migration project provisions its own resources. You do not manage that project as a replication instance. It can write a conversion assessment that counts what converts automatically and what needs a person.

That conversion report is still not the premigration assessment. One is about schema and code. The other is about whether a DMS task can run.

Report Asks Does not ask
Premigration assessment Can this DMS task run? Whether PL/SQL became PL/pgSQL
DMS Schema Conversion assessment What schema and code convert? Whether the replication instance is large enough
AWS SCT assessment A desktop view of conversion work It is not a serverless DMS task

Do not memorize the engine matrix

Supported pairs for data movement and supported pairs for schema conversion overlap and are not identical. AWS has added generative AI help for some conversion paths and not others. The console and the current user guide are the list. This course will not freeze a matrix that the next service update would make wrong.

Fifty tables have no primary key.                # task, and it also hurts CDC

Concept summary

  • Premigration assessment is about the DMS task.
  • DMS Schema Conversion and AWS SCT are about schema and code. SCT is the desktop tool.
  • Supported pairs live in the current guide, not in a memorized table.
